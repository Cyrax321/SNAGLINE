How it works

Monitoring that stays out of your way.

A thin adapter normalizes your agent's events into a canonical schema. The monitor runs deterministic detectors on every step. Alerts go to sinks. Nothing calls an LLM, nothing reads content, nothing blocks.

1

Adapter normalizes events

Raw Python loop, LangChain callback, LangGraph stream, or HTTP sidecar. Framework-specific code stays isolated in adapter modules.

with watch(monitor, "ep-1") as step:
  step("tool_call", tool_name="search", latency_ms=120)
2

Monitor runs detectors

Every registered detector sees every event. O(1) amortized. No network calls, no LLM calls.

3

FailureRisk dispatched to sinks

If a detector fires, the risk goes to every registered sink. Console, webhook, or your own. Only risk fields are transmitted, never content.

{"episode_id":"ep-1","score":0.5,"trigger":"loop",
  "detail":"action repeated 3x in last 3 steps"}
4

Fail-open by construction

Detector exceptions are caught and logged. Sink exceptions are caught and logged. The agent never stalls.

Detectors

Three failure modes. Deterministic detection.

Each detector is a protocol: observe an event, return a risk or nothing. No magic, no ML, no embeddings. Just sliding windows and running statistics.

loop Loop detector

Catches retry storms and stuck agents. Sliding window of action signatures. If the same signature repeats N times within W steps, it fires.

Sliding window + SHA-256 signature matching
cascade Error cascade detector

Catches fast cascades and slow-burn degradations. Two modes: N consecutive errors, or N errors within a recent window.

Consecutive counter + windowed counter
latency Latency anomaly detector

Catches sustained performance regression. Welford running mean and variance per tool, frozen baseline, CUSUM statistic. Warm-up prevents false positives.

Welford + Page CUSUM + frozen baseline
Features

Built for production agents.

Zero dependencies. Sensible defaults. Override what you need, ignore the rest.

Zero config, works today

Sensible defaults out of the box. Override thresholds when you need to. Every tunable knob lives in one dataclass.

monitor.py python 
from snagline import Monitor

monitor = Monitor.default()

# That's it. Loop + error cascade + latency
# detectors running. Console sink attached.
# Zero dependencies. Sub-microsecond overhead.

Tune when you need to

Every threshold, window size, and sensitivity parameter is a constructor argument. No config files, no env vars.

custom_config.py python 
from snagline import Monitor, Config

config = Config(
  loop_window_size=20,
  loop_repeat_threshold=5,
  cusum_k=0.3,
  cusum_h=3.0,
)

monitor = Monitor.default(config=config)

Integrations

Works with any agent runtime.

Four adapters ship in the box. Write your own in under 50 lines against a documented protocol.

Raw Python
Context manager + decorator. Stdlib only.
LangChain
Callback handler. Optional langchain-core.
LangGraph
Stream wrapper. Optional langgraph.
Claude Code
Native hook mapping via HTTP sidecar.
{}

HTTP sidecar

Any runtime that speaks HTTP can POST events. snagline serve --port 8787

|

Command bridge

Pipe hook payloads through the CLI. Always exits 0. Never blocks the agent.

~

File bridge

Tail a JSONL file. For frameworks that can only append to disk.
